## 📋 State Machine (Final)

### **Booking** (container — track payment + completion):
```
draft ──▶ paid ──▶ confirmed ──▶ complete
                          ▲
                    walk-in เข้าตรงนี้ (skip draft→paid)
```

- ❌ ไม่มี `cancelled`, `deleted`, `checked_in`, `no_show`
- Walk-in: skip `draft→paid` เข้า `confirmed` ตรงๆ (พนักงานจัดการเงินแยก)

### **BookingRoom** (รายการห้อง — track การเข้าพัก):
```
                    ┌──▶ checked_in ──▶ checked_out
draft ──▶ confirmed ┤
                    └──▶ no_show
```

- Walk-in: skip `draft→confirmed` เข้า `checked_in` ตรงๆ
- `no_show`: Admin manual รายห้อง แตกจาก `confirmed` เท่านั้น
- Draft expired: hard delete (via `CleanupExpiredDrafts`)
