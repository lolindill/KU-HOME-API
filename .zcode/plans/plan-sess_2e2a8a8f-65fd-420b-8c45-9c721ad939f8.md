# เติม Authorization Tests สำหรับ Draft Booking/Room Ops

**ผลการตรวจสอบ:** โค้ด production ทั้ง 5 endpoints (DELETE booking, POST/PUT/PUT-batch/DELETE room) **มี ownership check (owner หรือ admin → 403) ครบแล้ว** — ไม่ต้องแก้ production code เลย งานนี้เป็น **เติม tests อย่างเดียว** ใน `tests/Feature/BookingTest.php` เพื่อกัน regression

## Gaps ที่จะเติม

### A. `POST /bookings/{bookingId}/rooms` (addRooms) — ตอนนี้ **ไม่มี test เลย**
สร้าง section ใหม่ `✅ Add rooms to draft booking — POST /bookings/{bookingId}/rooms` (วางก่อน section "Update booking room") พร้อม tests:

1. **`test_owner_can_add_rooms_to_draft_booking`** — happy path: ใช้ helpers ที่มีแล้ว (`createRoomType` rate 1500/คืน + `createRoom` × 2 + `createDraftBooking` 1 ห้อง total 3000) → POST เพิ่ม 1 ห้อง 2 คืน → assert 200, `added_amount` = 3000, `total_amount` = 6000, `booking_rooms` count = 2, มี `addons` row ของห้องใหม่
2. **`test_admin_can_add_rooms_to_any_draft_booking`** — admin (`actingAsAdmin()`) เพิ่มห้องให้ booking ของ user อื่น → 200
3. **`test_user_cannot_add_rooms_to_other_users_booking`** — intruder (`User::factory()->create()`, role `user` เหมือนเจ้าของ) → assert **403** + BR count ไม่เปลี่ยน
4. **`test_unauthenticated_user_cannot_add_rooms`** — ไม่ล็อกอิน → **401**
5. **`test_add_rooms_to_non_draft_booking_returns_422`** — booking `status = 'paid'` (เจ้าของยิงเอง) → **422**
6. **`test_add_rooms_unknown_booking_returns_404`** — UUID สุ่ม → **404**

### B. Batch `PUT /bookings/{bookingId}/rooms` — ไม่มี test 403 non-owner
เพิ่มใน section "Batch update booking rooms" ที่มีอยู่:

7. **`test_user_cannot_batch_update_other_users_booking_rooms`** — intruder ยิง batch payload → assert **403** + `total_amount` และข้อมูล BR ทั้งคู่ไม่เปลี่ยน (all-or-nothing)

### C. 401 unauthenticated ของ room endpoints (ตอนนี้มีแค่ของ create + delete booking)
เพิ่มตาม section ที่มีอยู่:

8. **`test_unauthenticated_user_cannot_update_booking_room`** (section Update room) → **401**
9. **`test_unauthenticated_user_cannot_batch_update_booking_rooms`** (section Batch) → **401**
10. **`test_unauthenticated_user_cannot_delete_booking_room`** (section Delete room) → **401**

## แนวทาง (ทุกอย่างตาม pattern ที่มีแล้วในไฟล์)

- ใช้ helpers สำเร็จรูป: `createRoomType()` / `createRoom()` / `createDraftBooking()` / `actingAsAdmin()` — ไม่สร้าง helper ใหม่
- 401 ได้จาก `auth:sanctum` route middleware (แพตเทิร์นเดียวกับ `test_unauthenticated_user_cannot_delete_booking` บรรทัด 534)
- Happy path addRooms: availability check นับ existing BR ของ type เดียวกันด้วย เผื่อและวาง `createRoom()` 2 ห้อง (1 existing + 1 ใหม่ = 2 ≤ totalRooms)
- Comment หัว section ภาษาไทย + emoji ✅ ตามสไตล์เดิม
