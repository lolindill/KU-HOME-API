# Plan: Add Booking Rooms to Draft Booking API

เพิ่ม endpoint ใหม่ `POST /api/v1/bookings/{bookingId}/rooms` — เพิ่มห้องเข้า booking ที่สร้างไปแล้ว **เฉพาะเมื่อ booking อยู่ในสถานะ `draft`**

## สิ่งที่จะทำ (4 ไฟล์)

### 1. สร้าง Form Request ใหม่ `app/Http/Requests/AddBookingRoomsRequest.php`
- โครงสร้างเหมือน `StoreBookingRequest` (nested `booking_rooms.*`) แต่ **ไม่มี `source`** (booking สร้างไปแล้ว)
- ฟิลด์เดียวกันทุกตัว: `room_type_id`, `check_in`, `check_out`, `extra_beds`, `guests`, `has_children`, `billing_address`, `billing_comment`, `addons`
- Thai messages เหมือนเดิม (copy มาเฉพาะที่เกี่ยวกับ booking_rooms)

### 2. เพิ่ม method `addRooms()` ใน `app/Http/Controllers/Api/V1/BookingController.php`
วางก่อน `createBooking()` (logical grouping) — reuse logic จาก `createBooking` lines 142-260:

1. **Auth + ownership guard:**
   - `$userId = $request->user('sanctum')?->id` → 401 ถ้าไม่ล็อกอิน
   - โหลด booking → 404 ถ่าไม่พบ
   - `if ($booking->user_id !== $userId && $user->role !== 'admin')` → **403**
2. **🔒 Draft guard (core constraint):**
   - `if ($booking->status !== 'draft')` → **422** "ไม่สามารถเพิ่มห้องได้ เนื่องจากการจองไม่ได้อยู่ในสถานะ draft ค่ะ"
3. **Transaction:** `DB::beginTransaction()`
4. **Availability check:** reuse pattern จาก `createBooking` lines 142-183 — group by `room_type_id`, นับ existing overlapping `['draft','confirmed','checked_in']` BRs + batch overlaps, ปฏิเสธถ้าเกิน `Room::where('room_type_id',$rtId)->count()`
   - 🌟 **สำคัญ:** existing count รวมห้องที่อยู่ใน booking นี้แล้วด้วย (เพราะมี status `draft` และ overlap อยู่แล้ว — นับถูกอยู่แล้ว ไม่ต้อง exclude)
5. **สร้าง BookingRoom + Addon:** clone loop จาก `createBooking` lines 200-260 (อ่าน rate จาก `GlobalRate`, สร้าง BR `status='draft', room_id=null`, สร้าง `Addon`)
6. **อัปเดต total_amount:** recompute โดย sum ทั้ง booking ใหม่ (existing + new) — ใช้ `$booking->bookingRooms()->sum(...)` pattern หรือ accumulate `$booking->total_amount + $newTotal` (เลือก accumulate จาก `createBooking` pattern)
7. **Commit** → return 200 `{"status":"success","message":"...","booking_id","total_amount","payment_deadline"}`
8. **Error handling:** เหมือน `createBooking` (422/401 surface message, อื่นๆ log + generic 500)

### 3. Route ใน `routes/api.php`
วางใน `auth:sanctum` group (หลังบรรทัด 79 `createBooking`):
```php
Route::post('/bookings/{bookingId}/rooms', [BookingController::class, 'addRooms'])
    ->where('bookingId', '[0-9a-f\-]{36}')
    ->middleware('throttle:5,1');
```
ไม่ได้อยู่ใน `role:admin` group เพราะ owner ต้องใช้ได้ด้วย (ownership check ทำใน controller)

### 4. บันทึกการตัดสินใจใน `cline.md`
เพิ่ม entry ในส่วนที่เกี่ยวข้องว่ามี endpoint ใหม่ + state constraint (draft เท่านั้น)

## สิ่งที่จะไม่ทำ (เพื่อตรง convention)
- ❌ **ไม่เรียก RoomAllocator** — draft booking ยังไม่จ่ายห้อง (เหมือน `createBooking`)
- ❌ **ไม่เรียก `transitionStatus()`** — ห้องใหม่สร้างด้วย `status='draft'` ตรงๆ (initial state ไม่ใช่ transition)
- ❌ **ไม่เขียน status_change_logs เอง** — ไม่มี transition เกิดขึ้น
- ❌ **ไม่ทำซ้ำ StoreBookingRoomRequest** (file เก่าที่ไม่ได้ใช้) — สร้าง request ใหม่เพื่อรองรับ array shape + addons แบบเดียวกับ `createBooking`
